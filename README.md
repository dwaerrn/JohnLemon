# Лабораторна робота 8

AR-застосунок для Android на Unity з відстеженням зображення-маркера. Коли камера бачить маркер, на ньому з'являється персонаж JohnLemon. Ним можна керувати за допомогою екранного джойстика.

## Технології

- Unity 6 (6000.0.85f2), платформа Android
- AR Foundation 6.5 + ARCore (Image Tracking)
- Input System, UI (Canvas)

## Як це працює

1. `ARTrackedImageManager` шукає маркер з бібліотеки `Assets/_ARMarker/Markers/ReferenceImageLibrary`.
2. Коли маркер знайдено, створюється префаб `JohnLemon.prefab`:
   - `JohnLemonAnchor` — порожній об'єкт, який AR Foundation прив'язує до маркера;
   - `JohnLemon` — дочірній об'єкт: персонаж з аніматором і скриптом руху.
3. Персонаж стає видимим лише тоді, коли маркер стабільно відстежується (`TrackingState.Tracking`).
4. Гравець керує персонажем джойстиком, і той ходить по площині маркера.

## Керування

Екранний джойстик унизу екрана задає напрямок руху відносно камери:

- вгору — від камери;
- вниз — до камери;
- вліво / вправо — вліво / вправо на екрані.

Діагоналі теж працюють. Персонаж повертається в бік руху. Анімація перемикається між Idle і Walk.

## Скрипти

| Файл | Призначення |
|------|-------------|
| `Assets/CirclePad.cs` | Екранний джойстик. Передає напрямок через статичну властивість `CirclePad.Value`. |
| `Assets/ARPlayerMovement.cs` | Рух і поворот персонажа відносно маркера, параметр аніматора `IsWalking`, приховування персонажа до стабільного відстеження. |

Основні параметри `ARPlayerMovement` (в Inspector):

- **Walk Speed** — швидкість ходьби в одиницях персонажа за секунду;
- **Turn Speed** — швидкість повороту;
- **Camera Relative** — рух відносно камери або відносно маркера;
- **Wait For Good Tracking** — не показувати персонажа, доки маркер не відстежується стабільно.

## Запуск

1. Відкрити проєкт в Unity 6 і сцену `Assets/Scenes/AR_Marker`.
2. **File → Build Profiles** → Android → **Switch Platform**.
3. Під'єднати телефон з підтримкою ARCore і натиснути **Build and Run**.
4. Навести камеру на надрукований маркер.

У редакторі можна перевірити рух через XR Simulation (**Play**), керуючи джойстиком мишею.

## Примітки

- Для кращого розпізнавання в бібліотеці маркерів варто ввімкнути **Specify Size** і вказати реальну ширину надрукованого маркера в метрах.
- Маркер має бути контрастним, детальним, без повторюваних візерунків. Друкувати краще на матовому папері.
