AR-застосунок для Android на Unity з відстеженням зображення-маркера. Коли камера бачить маркер, на ньому з'являється персонаж JohnLemon. Ним можна керувати за допомогою екранного джойстика.

## Керування

Екранний джойстик унизу екрана задає напрямок руху відносно камери:

- вгору — від камери;
- вниз — до камери;
- вліво / вправо — вліво / вправо на екрані.

Діагоналі теж працюють. Персонаж повертається в бік руху. Анімація перемикається між Idle і Walk.

## Скрипти

| Файл | Призначення |
|------|-------------|
| `Assets/CirclePad.cs` | Екранний джойстик. Передає напрямок через статичну властивість `CirclePad.Value`. |
| `Assets/ARPlayerMovement.cs` | Рух і поворот персонажа відносно маркера, параметр аніматора `IsWalking`, приховування персонажа до стабільного відстеження. |

Основні параметри `ARPlayerMovement` (в Inspector):

- **Walk Speed** — швидкість ходьби в одиницях персонажа за секунду;
- **Turn Speed** — швидкість повороту;
- **Camera Relative** — рух відносно камери або відносно маркера;
- **Wait For Good Tracking** — не показувати персонажа, доки маркер не відстежується стабільно.
